# แอปวัดหน้างาน → AutoCAD (DXF) — เอกสารออกแบบ

วันที่ 21 ต.ค. 2569 · สถานะ: ร่างรอผู้ใช้อนุมัติ

## 1. เจตนาและเหตุผล

ผู้ใช้เป็นวิศวกรโยธาของเทศบาล ออกไปวัดหน้างานคนเดียวด้วย**เทปวัดและกล้องระดับ** (ไม่มีเครื่องวัดระยะเลเซอร์)
งานส่วนใหญ่คือ **สร้างถนนใหม่ / ปรับปรุงถนน / ปรับปรุงห้องน้ำ** ปัจจุบันจดลงกระดาษ แล้วกลับมาคิดค่าระดับและเขียนแบบใน AutoCAD เอง
ปัญหาที่ต้องการแก้: จดไม่ครบต้องกลับไปวัดซ้ำ · คิดค่าระดับผิด · เสียเวลาแปลงตัวเลขจากสมุดเป็นแบบ

เป้าหมาย: เว็บแอปหน้าเดียวบนมือถือ จดตัวเลขหน้างานตามฟอร์มของแต่ละประเภทงาน แล้วกดส่งออกเป็น **DXF** ที่เปิดใน AutoCAD
แล้วได้ **แปลน + รูปตัดตามขวาง** (ถนน) หรือ **แปลนพร้อมเส้นบอกระยะ** (ห้องน้ำ) พร้อมเขียนแบบต่อได้ทันที

## 2. เป้าหมาย / ไม่ใช่เป้าหมาย / สิ่งที่ถือว่าล้มเหลว

**เป้าหมาย**
- ใช้ได้บนมือถือโดยไม่ต้องมีเน็ต (ไฟล์ HTML ไฟล์เดียว เปิดจากเครื่องได้ · ข้อมูลเก็บในเครื่องอัตโนมัติ ไม่หายเมื่อปิดเบราว์เซอร์)
- ฟอร์มบอกเองว่าต้องวัดอะไร ตามประเภทงานที่เลือก (ข้อ 3 ของผู้ใช้)
- ถนน: จดเป็นสถานี ระยะสถานี**ปรับได้** (10 / 20 / 25 / 50 m หรือพิมพ์เอง) และแทรกสถานีพิเศษได้ (เช่น 0+037.5 ตรงท่อลอด)
- สมุดระดับในตัว: ใส่ BM แล้วจด BS / IS / FS → โปรแกรมคิด RL และตรวจ ΣBS − ΣFS ให้
- รูปตัดตามขวางแต่ละสถานี: จุด "กึ่งกลางถนน" มีเสมอ จุดอื่นเพิ่มได้ไม่จำกัด (ระยะซ้าย/ขวาจากกึ่งกลาง + RL หรือค่าอ่านไม้)
- ส่งออก DXF (ASCII, R12/R2000 ที่ AutoCAD ทุกรุ่นเปิดได้) และ CSV/JSON สำรอง
- ส่งออก/นำเข้าไฟล์โครงการ (JSON) เพื่อย้ายระหว่างมือถือกับคอม

**ไม่ใช่เป้าหมาย (รอบนี้)**
- ไม่ทำรูปตัดตามยาว (profile) — ผู้ใช้ระบุว่าใช้แค่แปลน + รูปตัดตามขวาง (เก็บโครงสร้างข้อมูลให้ทำเพิ่มทีหลังได้)
- ไม่ทำแผนที่/GPS · ไม่ถ่ายรูป · ไม่ซิงก์ผ่านเซิร์ฟเวอร์
- ไม่คำนวณปริมาณดินตัด-ถม (อาจทำเป็นรุ่นถัดไป เพราะมีรูปตัดอยู่แล้ว)
- ไม่ทำกรอบชื่อแบบ (title block) ของเทศบาล — ผู้ใช้วางแบบลงใน template ของตัวเองใน AutoCAD

**ถือว่าล้มเหลวแม้โปรแกรมทำงานได้**
- เปิด DXF แล้วเส้นอยู่คนละชั้น/คนละสเกลจนต้องจัดใหม่ทั้งหมด
- กรอกหน้างานช้ากว่าจดกระดาษ (ปุ่มเล็ก ต้องเลื่อนหาเยอะ ไม่มีค่าเริ่มต้น)
- ข้อมูลหายเมื่อแบตหมดหรือเบราว์เซอร์ปิด

## 3. ข้อจำกัด
- ทำงานบนเบราว์เซอร์มือถือ (Chrome/Safari) หน้าจอแคบ ใช้นิ้วเดียว กลางแดด → ตัวอักษรใหญ่ คอนทราสต์สูง ช่องกรอกตัวเลขเรียกแป้นตัวเลข
- ไม่มีเน็ตหน้างาน → ไม่พึ่ง CDN; ไลบรารีทั้งหมดฝังในไฟล์เดียว (หรือไม่ใช้ไลบรารีเลย)
- เครื่องมือวัด: เทป (ระยะราบ) + กล้องระดับ (ค่าระดับ)
- ผลลัพธ์ต้องเป็น DXF ที่ AutoCAD เปิดได้โดยไม่ต้องแปลง

## 4. ส่วนที่ตัดสินใจแล้ว (ตามที่คุยกับผู้ใช้)

### 4.1 โครงสร้างแอป
- หน้าแรก: รายการโครงการ (ชื่อ · ประเภท · วันที่) + ปุ่มสร้างใหม่ / นำเข้า JSON
- สร้างโครงการ: เลือกประเภท **สร้างถนนใหม่ / ปรับปรุงถนน / ปรับปรุงห้องน้ำ** → ได้ฟอร์มของประเภทนั้น
- ทุกหน้ามีปุ่ม "ส่งออก DXF" และ "สำรอง JSON"

### 4.2 งานถนน (ทั้งสร้างใหม่และปรับปรุง)
**ตั้งค่าโครงการ:** ชื่อสาย · สถานีเริ่ม (ค่าเริ่มต้น 0+000) · ความยาว · **ระยะสถานี (ปรับได้)** · BM (ชื่อ + ค่าระดับ, ใส่ได้หลายตัว) · หน่วย: ระยะเป็นเมตร ระดับเป็นเมตร 3 ตำแหน่ง

**หน้าสถานี (เลื่อนซ้าย-ขวาทีละสถานี):**
- ความกว้างผิวทางเดิม ซ้าย/ขวาจากกึ่งกลาง · ไหล่ทาง ซ้าย/ขวา · เขตทาง ซ้าย/ขวา (ช่องว่างได้)
- ชนิดผิวเดิม (ลูกรัง / คสล. / แอสฟัลต์ / หินคลุก / ดิน) และสภาพ (ดี / ชำรุด / เป็นหลุม)
- **รูปตัด:** ตารางจุด `ระยะจากกึ่งกลาง (−ซ้าย/+ขวา, m)` · `ค่าอ่านไม้ หรือ RL` · `ป้ายชื่อจุด` (ตัวเลือกด่วน: กึ่งกลาง · ขอบผิวทาง ซ.·ข. · ไหล่ ซ.·ข. · ร่องน้ำ ซ.·ข. · เขตทาง ซ.·ข.) — จุด "กึ่งกลาง" สร้างให้อัตโนมัติ
- สิ่งที่พบ (ติ๊กแล้วใส่ระยะจากกึ่งกลาง): เสาไฟ · ท่อลอด/ท่อระบายน้ำ (ขนาด) · บ่อพัก · รั้ว/บ้าน · ต้นไม้ · ทางแยก · อื่นๆ (ข้อความ)
- หมายเหตุอิสระ
- ปรับปรุงถนน เพิ่มช่อง: ความหนาผิวเดิมที่เจาะดู (cm) · ช่วงที่ต้องรื้อ

**สมุดระดับ:** ตารางลำดับการอ่านไม้ `จุด | BS | IS | FS | HI | RL | หมายเหตุ` ผูกกับสถานี/จุดในรูปตัดได้ · คิด HI, RL อัตโนมัติ · แสดง ΣBS − ΣFS และ RL สุดท้าย − RL แรก พร้อมเตือนถ้าไม่เท่ากัน · ปิดวงรอบกลับ BM ได้ (แสดงค่าคลาดเคลื่อน)

### 4.3 งานห้องน้ำ
- ผังห้องเป็นรูปหลายเหลี่ยมมุมฉาก: จดผนังทีละด้านวนตามเข็มนาฬิกา (ความยาว + ทิศ ซ้าย/ขวา/ขึ้น/ลง) · โปรแกรมตรวจว่ารูปปิดสนิท (ผลต่างต้องเป็น 0) ถ้าไม่ปิดแจ้งระยะที่ขาด
- บนผนังแต่ละด้าน: ช่องเปิด (ประตู/หน้าต่าง/ช่องระบายอากาศ) ระบุระยะจากมุมเริ่ม + ความกว้าง + ความสูง + ระดับธรณี
- สุขภัณฑ์เดิม: โถส้วม (นั่งราบ/นั่งยอง) · อ่างล้างหน้า · โถปัสสาวะ · ฝักบัว · ก๊อก · ท่อน้ำทิ้ง/floor drain — ระบุตำแหน่ง (x, y จากมุมอ้างอิง) และสภาพ (ใช้ได้/เปลี่ยน)
- ความสูงฝ้า · ระดับพื้นเทียบทางเดิน · ชนิดพื้น/ผนังเดิม · หลายห้องในหนึ่งโครงการได้ (ชาย/หญิง/ผู้พิการ)

### 4.4 ผลลัพธ์ DXF
- หน่วยวาด: **เมตร** (1 หน่วย = 1 m) ในสเปซ Model · ผู้ใช้จัดสเกลใน Layout เอง
- **ถนน – แปลน:** เส้นกึ่งกลาง (polyline ตามความยาว, แนวตรงจากซ้ายไปขวา) · ขีดสถานีพร้อมข้อความ `0+025` · เส้นขอบผิวทางซ้าย/ขวา (ต่อจุดจากความกว้างแต่ละสถานี) · เส้นไหล่ทาง · เส้นเขตทาง · สัญลักษณ์และข้อความสิ่งที่พบ
- **ถนน – รูปตัดตามขวาง:** เรียงเป็นตารางใต้แปลน (เช่น 3 รูปต่อแถว) แต่ละรูปมี: เส้นดิน (polyline จากจุดวัด) · เส้นกึ่งกลาง · ป้ายสถานีและ RL กึ่งกลาง · ค่าระยะและ RL กำกับทุกจุด · เส้นกริดระดับ · **สเกลดิ่งขยาย** เลือกได้ 1:1, 2:1, 5:1, 10:1 (ค่าเริ่มต้น 5:1)
- **ห้องน้ำ – แปลน:** ผนังเป็น polyline (เส้นคู่ ความหนาผนังที่ระบุ ค่าเริ่มต้น 0.10 m) · ช่องเปิดเป็นช่องว่างพร้อมสัญลักษณ์บานเปิด · สุขภัณฑ์เป็น block สี่เหลี่ยม/วงกลมพร้อมข้อความ · เส้นบอกระยะ (DIMENSION หรือเส้น+ข้อความ) ทุกด้านและทุกช่องเปิด
- **ชั้น (layer) คงที่ ชื่ออังกฤษ ไม่มีช่องว่าง:** `CL`, `EDGE-EXIST`, `SHOULDER`, `ROW`, `STA-TEXT`, `XS-GROUND`, `XS-GRID`, `XS-TEXT`, `FEATURE`, `WALL`, `OPENING`, `FIXTURE`, `DIM`, `TEXT`, `NOTE` — สีต่างกันตามชั้น
- ข้อความภาษาไทยในแบบ: ใช้ฟอนต์ที่ AutoCAD รองรับ (กำหนด STYLE เป็น Tahoma/Angsana ตามที่ผู้ใช้เลือกในตั้งค่า) · ตัวเลขและรหัสใช้อังกฤษ
- ชื่อไฟล์: `<ชื่อโครงการ>_<วันที่>.dxf`

### 4.5 การส่งไฟล์เข้าคอม
- ปุ่มดาวน์โหลดไฟล์ลงเครื่อง · ผู้ใช้ส่งต่อด้วยวิธีใดก็ได้ (USB, อีเมล, LINE, Google Drive) · แอปไม่ยุ่งเรื่องนี้

## 5. ส่วนที่ผมเลือกเอง (ผู้ใช้ยังไม่ได้ยืนยัน)
- HTML ไฟล์เดียว ไม่ใช้ไลบรารีภายนอก (เขียน DXF เองเพราะโครงสร้างไม่ซับซ้อน) → เปิดออฟไลน์ได้ 100 %
- เก็บข้อมูลด้วย localStorage/IndexedDB + ปุ่มสำรอง JSON (เตือนให้สำรองทุกครั้งที่ปิดงาน)
- รูปแบบสถานี `k+mmm.m` (เช่น 0+025, 1+237.5)
- ค่าเริ่มต้นระยะสถานี 25 m · สเกลดิ่งรูปตัด 5:1
- ระยะวัดทางราบรับทศนิยม 2 ตำแหน่ง (cm) · ค่าอ่านไม้/RL 3 ตำแหน่ง (mm)
- หน้าสถานีมีปุ่ม "คัดลอกจากสถานีก่อนหน้า" เพื่อกรอกเร็วเมื่อหน้าตัดคล้ายกัน
- รองรับไฟล์โครงการนำเข้า/ส่งออกเป็น JSON เวอร์ชันระบุไว้ในไฟล์ เผื่อขยายทีหลัง

## 6. ที่เหลือให้ผู้สร้างตัดสินใจ
- การจัดวางหน้าจอและลำดับช่องกรอก (ภายใต้ข้อจำกัดข้อ 3)
- รายละเอียดสัญลักษณ์ในแบบ (ขนาดตัวอักษร ความยาวขีดสถานี รูปสุขภัณฑ์)
- วิธีตรวจสอบว่า DXF เปิดได้: อย่างน้อยทดสอบเปิดด้วย ezdxf/ODA viewer หรือ LibreCAD ก่อนส่งมอบ
- ภาษาในหน้าจอ: ไทยทั้งหมด ยกเว้นรหัส/หน่วย
