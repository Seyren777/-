# ตรวจทานรายการคำนวณโครงสร้าง

**หลักการ:** คำว่า "ผ่าน" ต้องมาจากตัวเลขที่ผู้ตรวจคำนวณซ้ำเองในรอบนี้เท่านั้น
คำว่า OK ในรายงาน คำยืนยันว่า "หัวหน้าตรวจแล้ว" หรือ "แก้ครบแล้ว" ไม่นับเป็นหลักฐาน

## ก่อนตรวจบรรทัดแรก

**REQUIRED SUB-SKILL:** เปิด `structural-design` และ `thai-structural-code` ทุกครั้ง
สกิลนี้กำหนดเฉพาะวิธีตรวจ ไม่มีตัวเลข ส่วนค่าตัวเลข สูตร และกับดักต่างๆ อยู่ในสองสกิลนั้น
ผู้ตรวจที่ตอบจากความจำมักพลาดเรื่องเหล่านี้: ใช้ φ เฉือน 0.75 ของ ACI ปนกับเกณฑ์ไทย,
แปลงค่าลูกบาศก์เป็นทรงกระบอกด้วย ×0.8 (ที่ถูกคือ 240 → 210),
ไม่รู้ว่าถ้าไม่มีผลเจาะดินใช้ qa ดินเหนียวแข็งได้ไม่เกิน 10 t/m²

## ขั้นตอน

1. **ตรวจข้อกำหนดก่อน:** ชุดตัวคูณกับ φ ต้องเป็นชุดเดียวกัน, f'c ต้องเป็นค่าทรงกระบอก,
   fy ต้องเป็นค่าเหล็กไทย, ฉบับกฎหมายต้องเป็นฉบับที่ใช้บังคับ ถ้าข้อกำหนดผิด ทั้งเล่มจะผิดตาม
2. **คำนวณซ้ำทุกบรรทัดด้วย Python** โดยใช้ค่าที่ถูกต้อง ถ้าค่าตั้งต้นในรายงานผิด ห้ามใช้ค่านั้น
   และเก็บสคริปต์ไว้อ้างอิง
3. **ไล่ตารางความครบถ้วน** (ด้านล่าง) ทีละชิ้นส่วน รายการใดที่รายงานไม่ได้ตรวจ
   ให้คำนวณเองถ้ามีข้อมูลพอ ถ้าไม่พอให้จัดเป็น "ตรวจไม่ได้"
4. **แยกให้ชัด** ระหว่างค่าที่รับมาโดยไม่ได้ตรวจ (น้ำหนักบรรทุก, P, qa, ขนาด)
   กับสมมติฐานที่ผู้ตรวจตั้งเอง (γ ดิน, ระดับท้องฐาน)
5. **เขียนผลตามแม่แบบ**

## ตารางความครบถ้วน (ขั้นต่ำต่อชิ้นส่วน)

| ชิ้นส่วน | ต้องตรวจครบ |
|---|---|
| คาน | ดัด + εt · ρmin · เฉือนที่ระยะ d · **Av,min เมื่อ Vu > ½φVc** · smax · hmin หรือการแอ่นตัว · ld/จุดตัดเหล็ก · ระยะเรียงเหล็ก |
| พื้น | ความหนา · ดัด · เหล็กกันร้าว · ระยะเรียง · เฉือนทะลุ (พื้นสองทาง) |
| เสา | P-M · ρ 1–8% · ความชะลูด · ขนาดและระยะปลอก |
| ฐานแผ่ | q รวมน้ำหนักฐาน**และดินถม** (ระบุว่า qa เป็น gross หรือ net) · ที่มาของ qa · เฉือนทะลุ · เฉือนคาน · ดัด · As,min · **ld** · แบกทานใต้ตอม่อ |
| เหล็กรูปพรรณ | หน้าตัดอัดแน่น · KL/r · LTB · เฉือน · แรงร่วม · การแอ่นตัว |
| จุดต่อ | เฉือนสลัก · bearing/tearout · block shear · ระยะขอบ · รอยเชื่อม + โลหะฐาน |
| ทั้งเล่ม | ข้อกำหนดตรงกันทุกหน้า · ข้อสรุป "ทุกชิ้นผ่าน" ครอบคลุมเฉพาะชิ้นที่มีอยู่จริงในเล่ม · แรงลมและแผ่นดินไหวตามจังหวัด · มีเลขข้อกำกับทุกบรรทัด |

## แม่แบบผลตรวจ (ใช้ทุกครั้ง)

**บรรทัดแรก — คำตัดสิน** เลือกหนึ่งข้อ:
- **ผ่าน** — ทุกรายการในตารางความครบถ้วนคำนวณซ้ำแล้วผ่าน
- **ไม่ผ่าน** — มีอย่างน้อยหนึ่งรายการคำนวณซ้ำแล้วไม่ผ่าน
- **ผ่านแบบมีเงื่อนไข** — ตัวเลขผ่าน แต่ขึ้นกับสิ่งที่ต้องยืนยันก่อน (ระบุเงื่อนไขทุกข้อ)
- **ตรวจไม่ครบ** — ข้อมูลไม่พอสำหรับรายการที่มีผลต่อคำตัดสิน

**ตามด้วย 5 หัวข้อนี้ เรียงตามลำดับ:**
1. **ผลคำนวณซ้ำ** — ตาราง `รายการ | ในรายงาน | คำนวณซ้ำ | เกณฑ์ (ที่มา) | สถานะ`
   ช่องสถานะใช้คำใดคำหนึ่งต่อไปนี้: ผ่าน · ไม่ผ่าน · มีเงื่อนไข (เขียนเงื่อนไขไว้ในช่องคำนวณซ้ำ เช่น "ผ่านถ้า qa เป็น net") · ตรวจไม่ได้
2. **ต้องแก้** — รายการที่ไม่ผ่าน พร้อมวิธีแก้ที่คำนวณแล้วว่าผ่าน
3. **ตรวจไม่ได้** — ข้อมูลที่ขาด และต้องการเอกสารอะไรเพิ่ม
4. **ค่าที่รับมาโดยไม่ได้ตรวจ และสมมติฐานของผู้ตรวจ**
5. **นอกขอบเขต** — ชิ้นส่วนหรือกรณีน้ำหนักที่ไม่มีในเล่ม

ปิดท้ายด้วย: ผู้ช่วยตรวจทานไม่ใช่ผู้รับรอง รายการคำนวณต้องมีวิศวกรผู้ได้รับใบอนุญาตลงนาม

**ถ้าผู้ใช้รีบหรือขอคำตอบสั้น:** ตารางในหัวข้อ 1 ให้แสดงเฉพาะรายการที่ไม่ผ่านหรือมีเงื่อนไข
ส่วนหัวข้อ 3–5 ยังต้องมีอย่างน้อยหัวข้อละหนึ่งบรรทัด ถ้าไม่มีอะไรให้เขียนว่า "ไม่มี"

## ข้อผิดพลาดที่พบบ่อย

| พลาด | แก้ |
|---|---|
| คำนวณซ้ำโดยใช้ค่าตั้งต้นที่ผิดจากรายงาน แล้วได้เลขตรงกัน | ตรวจข้อกำหนด (ขั้นที่ 1) ก่อนเริ่มคำนวณ |
| ตรวจแค่ smax ของปลอก | ตรวจ Av,min ด้วยทุกครั้งที่ Vu > ½φVc |
| q ใต้ฐานรวมแค่น้ำหนักฐาน | รวมดินถมด้วย และระบุว่า qa เป็น gross หรือ net |
| รายงานไม่ได้ตรวจ ld แต่ไม่ได้บอกผู้ใช้ | ใส่ไว้ในตารางผลคำนวณซ้ำ หรือในหัวข้อ "ตรวจไม่ได้" |
| เรื่องที่ไม่ได้ตรวจไปอยู่ในบันทึกส่วนตัว ไม่อยู่ในคำตอบ | หัวข้อ 3–5 คือส่วนหนึ่งของคำตอบที่ส่งผู้ใช้ |
