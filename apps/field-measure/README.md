# วัดหน้างาน (field-measure)

แอปจดข้อมูลสำรวจหน้างาน (ถนน / ห้องน้ำ) บน iPhone แล้วส่งออกเป็นไฟล์ DXF เปิดใน AutoCAD 2027
ทำงานได้ออฟไลน์ ข้อมูลเก็บในเครื่อง ไม่ส่งขึ้นเซิร์ฟเวอร์

## 1. วิธีเปิดใช้ GitHub Pages (3 คลิก)

ทำครั้งเดียว ที่คอมพิวเตอร์หรือมือถือก็ได้

1. เปิด repo `Seyren777/-` บน GitHub → แท็บ **Settings** → เมนูซ้าย **Pages**
2. ที่หัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก `claude/add-superpowers-skills` และโฟลเดอร์ `/ (root)`
3. กด **Save** แล้วรอ 1–2 นาที

จากนั้นเปิดลิงก์: **https://seyren777.github.io/-/apps/field-measure/**

หมายเหตุ: ถ้าภายหลังรวม (merge) branch นี้เข้า `master` แล้ว ให้กลับมาที่ Settings → Pages
แล้วเปลี่ยน Branch เป็น `master` (ไม่เช่นนั้นลิงก์จะค้างอยู่กับ branch เก่า)

## 2. วิธีติดตั้งลง iPhone

1. เปิดลิงก์ข้างบนใน **Safari** (ต้อง Safari เท่านั้น ไม่ใช่ Chrome)
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → เลื่อนลง → **"เพิ่มไปยังหน้าจอโฮม"** → เพิ่ม
3. ต่อไปเปิดจากไอคอนบนหน้าจอโฮม

- หลังเปิดครั้งแรกขณะมีเน็ต แอปจะโหลดตัวเองเก็บไว้ในเครื่อง ใช้ออฟไลน์ได้ (หน้าจอจะขึ้น "พร้อมใช้ออฟไลน์")
- ถ้าแอปมีการอัปเดตใหม่ ให้เปิดแอปขณะมีเน็ตหนึ่งครั้ง (อาจต้องเปิด-ปิดแอปอีกรอบจึงจะได้เวอร์ชันใหม่)

## 3. การสำรองข้อมูล

ข้อมูลอยู่ในเครื่อง iPhone เท่านั้น iOS อาจล้างข้อมูลเว็บที่ไม่ได้เปิดเกิน 7 วัน
จึงต้องสำรองเสมอ

- **ก่อนปิดงานทุกครั้ง** ไปที่หน้า ส่งออก → กด **"สำรอง JSON"** แล้วเก็บไฟล์ไว้ (เช่น ใน Files / iCloud / ส่งเข้า LINE ตัวเอง)
- **นำเข้ากลับ**: หน้าแรก → **"นำเข้าไฟล์ JSON"** → เลือกไฟล์ที่สำรองไว้
  (ถ้ามีโครงการชื่อเดียวกันอยู่แล้ว แอปจะถามก่อนเขียนทับ)
- วิธีเดียวกันใช้ย้ายโครงการไปเครื่องอื่นได้

## 4. การใช้งานย่อ

**ถนน**
1. หน้าแรก → เลือกประเภท (สร้างถนนใหม่ / ปรับปรุงถนน) → ตั้งชื่อ → **สร้าง**
2. หน้า **ตั้งค่า**: สถานีเริ่ม (พิมพ์ `0+000`), ระยะสถานี (m), หมุด BM และระดับ (RL) → กด **สร้างสถานี**
   (กดซ้ำได้ ข้อมูลที่จดแล้วไม่หาย)
3. **กรอกทีละสถานี**: ค่าอ่านไม้จะไปลงในสมุดระดับให้เอง
4. **ตรวจสมุดระดับ**: แถบปิดวงรอบ: เขียว = คลาดเคลื่อนอยู่ในเกณฑ์, แดง = เกินเกณฑ์ (ต้องตรวจ/วัดซ้ำ), เทา = ไม่มีการปิดวงรอบ
   (ชื่อ BM ต้องตรงกับชื่อจุดในสมุดระดับ เพื่อเริ่มและปิดวงรอบ)
5. **ส่งออก DXF**

**ห้องน้ำ**
- จดผนังวนไป **ตามเข็มนาฬิกา** ทีละด้าน จนแอปขึ้น **"ปิดรูปสนิท"**
  (ถ้าไม่ปิด จะแจ้งระยะที่ขาด และใน DXF จะมีหมายเหตุ "ไม่ปิดรูป ขาด ... m")

## 5. เปิดใน AutoCAD

- AutoCAD: **File → Open** เลือกไฟล์ `.dxf` (หรือพิมพ์คำสั่ง `DXFIN`)
- ไฟล์เป็น DXF R2000, **หน่วยเมตร** (1 หน่วย = 1 m)

**Layer ทั้ง 15 และความหมาย**

| Layer | ความหมาย |
|---|---|
| CL | แนวกึ่งกลางถนน |
| EDGE-EXIST | ขอบผิวทางเดิม |
| SHOULDER | ไหล่ทาง |
| ROW | เขตทาง |
| STA-TEXT | ตัวเลขสถานี |
| XS-GROUND | เส้นดินเดิมในรูปตัดตามขวาง |
| XS-GRID | เส้นกริด/ระดับอ้างอิงของรูปตัด |
| XS-TEXT | ตัวเลขระดับและระยะในรูปตัด |
| FEATURE | สิ่งที่พบข้างทาง (วงกลมพร้อมป้ายชื่อ) |
| WALL | ผนัง (แปลนห้องน้ำ) |
| OPENING | ประตู / หน้าต่าง |
| FIXTURE | สุขภัณฑ์ |
| DIM | เส้นบอกขนาด |
| TEXT | ข้อความทั่วไป (ชื่อโครงการ ชื่อห้อง) |
| NOTE | หมายเหตุ / คำเตือน |

**สเกลพิมพ์** ที่ตั้งไว้: แปลนถนน 1:100, รูปตัดตามขวาง 1:25, แปลนห้องน้ำ 1:50
เปลี่ยนได้ที่หน้า **ตั้งค่า** (ขนาดตัวอักษรจะปรับตามสเกลให้เอง)

**ตัวอักษรไทย** ใช้ text style ชื่อ `STD` ฟอนต์ Tahoma / Angsana (ต้องมีฟอนต์นี้ในเครื่องที่เปิด AutoCAD)

**ถ้า AutoCAD แจ้ง error ตอนเปิดไฟล์ ให้ส่งข้อความ error กลับมา**
โครงสร้างไฟล์ตรวจด้วย ezdxf แล้ว แต่ยังไม่ได้ทดสอบกับ AutoCAD 2027 จริง

## 6. สำหรับผู้ดูแล

- **ทุกครั้งที่แก้ไฟล์ในแอป ต้องเปลี่ยนชื่อ cache ใน `sw.js`** (`const CACHE = 'fm-v2'` → `fm-v3` → `fm-v4` ...)
  ไม่เช่นนั้นมือถือที่ติดตั้งแล้วจะใช้ไฟล์เก่าจาก cache ต่อไป
  และถ้าเพิ่มไฟล์ใหม่ ต้องเพิ่มชื่อในรายการ `PRECACHE` ด้วย
- เส้นทางไฟล์ทั้งหมดเป็นแบบ relative (`./...`) จึงทำงานได้ใต้ sub-path ของ GitHub Pages
- รันเทสต์ (ที่ root ของ repo): `node --test tests/field-measure/*.test.mjs`
  (`tests/field-measure/check_dxf.py` ตรวจไฟล์ DXF ด้วย ezdxf)
- โครงสร้างไฟล์:
  - `index.html`, `style.css`, `manifest.json`, `icon.svg`, `sw.js` — เปลือกแอป / PWA / ออฟไลน์
  - `src/app.js` — router และการเริ่มต้น
  - `src/store.js` — เก็บข้อมูล, สำรอง/นำเข้า JSON
  - `src/level.js` — คำนวณสมุดระดับ
  - `src/road.js`, `src/toilet.js` — ตรรกะถนน / ห้องน้ำ
  - `src/dxf.js` — ตัวเขียนไฟล์ DXF R2000; `src/export.js` — วาดรูป + CSV
  - `src/views/*.js` — หน้าจอ (home, roadSettings, station, levelBook, toilet, exportPanel)
